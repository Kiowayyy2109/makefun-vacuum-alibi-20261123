Entry for the make.fun bounty **The Vacuum's Alibi: One Line, 200 Characters**.

`main.py` writes one line — the excuse a robot vacuum gives for missing a
spot — to `/output/entry.txt`. The line is a fixed string, so the program's
output is deterministic and byte-identical on every run.

The line:

> My cliff sensors detected a drop of 0.4 millimeters in that corner and I am not paid enough hazard pay to die for your crumbs.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, well under the 200-character cap).
